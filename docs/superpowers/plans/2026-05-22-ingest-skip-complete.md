# `--skip-complete` Ingest Flag Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `--skip-complete` flag to the `ingest` binary that skips species already in the DB with ≥1 recording and ≥1 image, enabling interrupted runs to be resumed without redundant API calls.

**Architecture:** A single upfront DB query fetches all complete ebird_codes before the worker pool starts. A helper function filters the full code list down to the remainder. Workers run unchanged on the filtered list.

**Tech Stack:** Go, sqlc (query codegen), pgx/v5, chi (not used here), Justfile task runner.

func TestFilterComplete(t *testing.T) {
	tests := []struct {
		name     string
		codes    []string
		complete map[string]struct{}
		want     []string
	}{
		{

### Step 2b: Implement the helper

- [ ] **Step 3: Add `filterComplete` to `main.go`**

Add this function to `backend/cmd/ingest/main.go`, just before `ingestSpecies`:

```go
func filterComplete(codes []string, complete map[string]struct{}) []string {
	out := make([]string, 0, len(codes))
	for _, c := range codes {
		if _, ok := complete[c]; !ok {
			out = append(out, c)
		}
	}
	return out
}
```

- [ ] **Step 2: Add the filter block after `codes` is built**

In `main()`, after `log.Printf("total unique species: %d", len(codes))` and before `sem := make(chan struct{}, *workers)`, add:

```go
if *skipComplete {
	completeCodes, err := q.ListCompleteSpeciesEbirdCodes(ctx)
	if err != nil {
		log.Fatalf("skip-complete: query complete species: %v", err)
	}
	complete := make(map[string]struct{}, len(completeCodes))
	for _, c := range completeCodes {
		complete[c] = struct{}{}
	}
	before := len(codes)
	codes = filterComplete(codes, complete)
	log.Printf("--skip-complete: skipping %d already-complete species, processing %d remaining", before-len(codes), len(codes))
}
```
