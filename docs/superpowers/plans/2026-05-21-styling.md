# Lifer Styling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Style all Svelte frontend views and components with dark/light themes, Inter font, and CSS custom properties.

**Architecture:** Global `src/app.css` holds the CSS reset and token layer (custom properties for both themes). Scoped `<style>` blocks in each `.svelte` file reference tokens via `var(--token)`. Theme switching uses a `data-theme` attribute on `<html>` toggled by `src/lib/theme.ts`, with localStorage persistence and `prefers-color-scheme` as default.

**Tech Stack:** Svelte 5, Vite 6, Vitest 4, @testing-library/svelte 5, Inter (Google Fonts)

```ts
type Theme = 'dark' | 'light'

const STORAGE_KEY = 'lifer-theme'

export function getCurrentTheme(): Theme {
  const attr = document.documentElement.getAttribute('data-theme') as Theme | null
  if (attr === 'dark' || attr === 'light') return attr
  return window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light'
}

export function initTheme(): void {
  const saved = localStorage.getItem(STORAGE_KEY) as Theme | null
  if (saved === 'dark' || saved === 'light') {
    document.documentElement.setAttribute('data-theme', saved)
  }
}

export function toggleTheme(): void {
  const next: Theme = getCurrentTheme() === 'dark' ? 'light' : 'dark'
  document.documentElement.setAttribute('data-theme', next)
  localStorage.setItem(STORAGE_KEY, next)
}
```

<script lang="ts">
  import { auth } from './stores/auth'
  import { view } from './stores/view'
  import { getCurrentTheme, toggleTheme } from './lib/theme'
  import Login from './views/Login.svelte'

  let theme = $state(getCurrentTheme())

          $auth = user
          $view = 'dashboard'

          $view = 'login'
        }

      .catch(() => {
        $view = 'login'

    toggleTheme()
